# Стартовый промпт: S2.5 — `remove_channel` (каскадное удаление канала)

## Задача

Добавить MCP-инструмент `remove_channel` и **5 новых repo-методов** `delete_source` / `delete_by_channel` для полного каскадного удаления канала и всех его данных из системы (3 базы данных, 10 таблиц).

Полная спецификация: **`docs/prompts/S2.5-remove-channel.md`** — внимательно прочитай перед началом работы.

## Контекст

В S2 были добавлены инструменты `add_channel`, `pause_channel`, `resume_channel`, `get_pipeline_status`, `trigger_pipeline`. Жизненный цикл канала неполный — отсутствует операция удаления. При ошибочном добавлении канала или при необходимости очистки — единственный способ удалить данные — ручные SQL-запросы.

Данные канала распределены по **3 отдельным PostgreSQL-базам** (ingestion, raw, processing), соединённым через отдельные SQLAlchemy-сессии. Кросс-БД транзакции невозможны — удаление идёт группами по базе с идемпотентностью.

## Архитектура хранения

### 3 базы данных (3 отдельных движка в `Database`)

```
Ingestion DB:  sources, comment_cursors, source_attempts
Raw DB:        raw_messages, raw_conflicts
Processing DB: document_embeddings, processed_documents, processing_failures,
               topic_cards, topic_bundles
```

### FK-ограничения (влияют на порядок удаления)

- `document_embeddings.source_ref → processed_documents(source_ref)` — **без CASCADE**. Эмбеддинги ОБЯЗАТЕЛЬНО удалять ДО processed_documents.
- Все остальные связи — логические, без FK в DDL.

### Обязательный порядок удаления

```
Processing DB (одна сессия, одна транзакция):
  1. document_embeddings   (FK-child → обязательно первой)
  2. processed_documents
  3. processing_failures
  4. topic_cards            (метод delete_by_channel уже существует)
  5. topic_bundles          (метод delete_by_channel уже существует)

Raw DB (одна сессия, одна транзакция):
  6. raw_conflicts          (ссылается на raw_messages.source_ref)
  7. raw_messages

Ingestion DB (одна сессия, одна транзакция):
  8. source_attempts
  9. comment_cursors
 10. sources                (последней)
```

Добавить **после** `export_repos()` (в конец файла). Нужны дополнительные импорты — `SAEmbeddingRepo` и `SAProcessingFailureRepo` уже импортируются в файле.

```python
@asynccontextmanager
async def removal_repos() -> "AsyncIterator[tuple[SAIngestionStateRepo, SARawMessageRepo, SAProcessedDocumentRepo, SAProcessingFailureRepo, SAEmbeddingRepo, SATopicCardRepo, SATopicBundleRepo, Database]]":
    """Context manager for channel removal (all three DB sessions)."""
    db = Database.from_settings(settings)
    try:
        await db.init()
        state_session = db.ingestion_state_session()
        raw_session = db.raw_storage_session()
        proc_session = db.processing_storage_session()
        try:
            yield (
                SAIngestionStateRepo(state_session),
                SARawMessageRepo(raw_session),
                SAProcessedDocumentRepo(proc_session),
                SAProcessingFailureRepo(proc_session),
                SAEmbeddingRepo(proc_session),
                SATopicCardRepo(proc_session),
                SATopicBundleRepo(proc_session),
                db,
            )
        finally:
            await state_session.close()
            await raw_session.close()
            await proc_session.close()
    finally:
        await db.close()
```

### S2.5.5: MCP-инструмент `remove_channel` в `mcp_server.py`

Добавить **после** `resume_channel` (после строки 557), в секции T5 — Channel Management:

```python
@mcp.tool()
async def remove_channel(
    channel_id: str,
    confirm: bool = False,
) -> RemoveChannelResult:
    """Permanently remove a channel and ALL its data from the knowledge base.
    This action is IRREVERSIBLE. You must set confirm=true to proceed.
    Removes: source config, raw messages, processed documents, embeddings,
    topics, and processing failures.

    Args:
        channel_id: Channel ID (with or without @).
        confirm: Safety flag — must be true to actually delete data."""
    normalized = channel_id.lstrip("@")

    if not confirm:
        return RemoveChannelResult(
            channel_id=normalized,
            removed=False,
            message="Safety check: set confirm=true to permanently delete all data for this channel. "
            "This action is IRREVERSIBLE.",
            details={},
        )

    if normalized in _running_pipelines:
        return RemoveChannelResult(
            channel_id=normalized,
            removed=False,
            message=f"Pipeline for '{normalized}' is currently running. "
            "Wait for it to finish or restart the server before removing.",
            details={},
        )

    from tg_parser.services.db_context import removal_repos

    async with removal_repos() as (
        state_repo, raw_repo, proc_repo, failure_repo,
        embedding_repo, topic_card_repo, topic_bundle_repo, _db,
    ):
        source = await state_repo.get_source(normalized)
        if source is None:
            return RemoveChannelResult(
                channel_id=normalized,
                removed=False,
                message=f"Channel '{normalized}' not found.",
                details={},
            )

        counts: dict[str, int] = {}

        # Processing DB (embeddings first due to FK)
        counts["embeddings"] = await embedding_repo.delete_by_channel(normalized)
        counts["processed_documents"] = await proc_repo.delete_by_channel(normalized)
        counts["processing_failures"] = await failure_repo.delete_by_channel(normalized)
        counts["topic_cards"] = await topic_card_repo.delete_by_channel(normalized)
        counts["topic_bundles"] = await topic_bundle_repo.delete_by_channel(normalized)

        # Raw DB
        counts["raw_messages"] = await raw_repo.delete_by_channel(normalized)

        # Ingestion DB (source last)
        existed = await state_repo.delete_source(normalized)
        counts["source"] = 1 if existed else 0

    total = sum(counts.values())
    return RemoveChannelResult(
        channel_id=normalized,
        removed=True,
        message=f"Channel '{normalized}' removed. {total} records deleted across all tables.",
        details=counts,
    )
```
