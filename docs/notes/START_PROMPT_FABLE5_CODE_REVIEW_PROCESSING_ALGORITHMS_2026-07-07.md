## Заметки для оператора (не часть промпта)

- **Эффорт.** По умолчанию `high`; для максимально тщательного прогона по всему списку файлов — `xhigh`. Не используй `budget_tokens` и prefill (Fable 5 их не поддерживает).
- **Refusal fallback.** Если запрос вернёт `stop_reason: "refusal"` (проект местами касается безопасности/скрейпинга) — настрой fallback на Claude Opus 4.8.
- **Почему нет «think step by step».** На Fable 5 адаптивное мышление всегда включено; явная просьба «показать рассуждение» может сработать как `reasoning_extraction`-refusal. Мышление модель ведёт сама.
- **Почему промпт не переусложнён.** Для Fable 5 длинные пошаговые сценарии ухудшают результат — заданы цель, контекст, ограничения и формат вывода, а «как» модель планирует сама.
- **Карта файлов** (`<repo_map>`) взята из инвентаризации репозитория и может устареть — в промпте явно велено читать реальные файлы и не доверять карте вслепую.
- **Сохранение отчёта.** Модель возвращает отчёт как Markdown прямо в ответе (read-only). Если нужен файл `.md` — сохрани вывод сам; модель файлы не создаёт.
