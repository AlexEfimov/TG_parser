# Архив документации

Здесь хранятся документы, отработавшие свою задачу: они не актуальны для текущего состояния проекта, но остаются как история разработки.

---

## 📝 Политика архивации

Документ архивируется когда:

1. Информация больше не актуальна для текущей версии;
2. существует более новая версия документа;
3. документ относится к старым подходам/архитектуре;
4. **(для `START_PROMPT_*`)** сессия, для которой он написан, завершена, и на файл **не ссылается ни один живой документ**.

Архивированные документы сохраняются для истории, **не обновляются** и не индексируются в основной документации.

> ⚠️ **Про ссылки.** `Lint Documentation` в CI (`markdown-link-check`) проверяет только `http(s)`-ссылки — все относительные пути он пропускает по конфигу. То есть перенос файла **не** уронит CI и **не** будет пойман им: битые относительные ссылки придётся искать самому. Отсюда критерий 4 — переносим только то, на что нет ни одной входящей ссылки; тогда сломать нечего по построению.
