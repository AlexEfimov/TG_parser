## Approved fix design (user-reviewed 2026-05-30 — apply in MCP-live chat)

**Status:** design ✅ approved by operator; **NOT yet applied** — `cursor-backend-control`
MCP was unavailable in the 2026-05-30 00:18–00:24 chat (`list_automations` →
`MCP server does not exist: cursor-backend-control`), so `get_automation` /
`update_automation` could not run. Re-run the start prompt in a chat where the
server is live; the design below is pre-approved, so go straight to apply.

**Deterministic prefix resolution (approved):**

```text
prefix_source =
    labels.rulename     if non-empty   # most stable: rule name
 else labels.alertname  if non-empty
 else "alert"                           # generic fallback only if both empty

prefix = "[" + normalize(prefix_source) + "]"

normalize(s):
  if s contains "5xx" -> "5xx"         # (b) keep 5xx-normalization → yields [5xx]
  else                -> s
```

- Branch selection depends ONLY on `rulename → alertname → const`; never on a
  field that is empty in part of the payloads (root cause of [5xx] vs [alert] flip).
- Operator decisions: **(a)** order `rulename → alertname → "[alert]"` = approved;
  **(b)** keep `5xx`-normalization (prefix stays `[5xx]`, not `[tg_api_5xx_spike]`).
