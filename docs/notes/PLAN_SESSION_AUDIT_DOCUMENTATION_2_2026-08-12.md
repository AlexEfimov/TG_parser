## 4. Метод покрытия (431 файл нельзя прочитать)

| Слой | Что | Как |
|---|---|---|
| **Полное чтение** | 7 роадмапов, 5 архитектур, `docs/notes/README.md`, `docs/archive/DOCUMENTATION_INDEX.md`, `tests/README.md` | читать целиком |

| **Механически** | остальные ~400 | `rg`-свипы: битые относительные ссылки, SoT-заявления, баннеры, счётчики/даты |
| **Не читать** | `docs/notes/archive/**`, `docs/prompts/**`, отработавшие START_PROMPT | только пересчёт объёма |

Свип на битые ссылки (обязателен, дал класс BUG-090):

```bash
rg -o '\]\(([^)]+\.md)\)' -r '$1' docs --glob '*.md' | sort -u | while IFS=: read -r src link; do
  d=$(dirname "$src"); [ -f "$d/$link" ] || echo "DEAD: $src -> $link"; done
```

**Прогон 2026-08-12 дал 207 попаданий — не пугаться и не чинить все.** Разложить по двум признакам, потому что это разные дефекты:

| Класс | Признак | Приоритет |
|---|---|---|
| Неверная база | ссылка вида `docs/USER_GUIDE.md` из файла внутри `docs/**` — цель существует, путь считан от корня репозитория | низкий; массовый; в план исполнительной сессии |
| Пропавшая цель | файла нет нигде | **разбирать**: либо документ удалён, либо ссылка врёт |

Основная масса — первый класс и почти вся она в `docs/archive/`. Приоритет — второй класс и любой класс **вне** `archive/`: ссылка из живого документа опаснее, чем из исторического.
