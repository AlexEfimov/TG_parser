## 2. Что меняется относительно плана 2026-09-23

1. **O1 теряет основание.** Перетопикизацию двух каналов планировали из-за шума в бандлах; его сняла пересборка R16 без LLM. Остаётся вопрос качества самих карточек — его симуляция не оценивала ([`R16_SUPPORTING_SIMULATION_2026-11-16.md`](R16_SUPPORTING_SIMULATION_2026-11-16.md) §7, решение 5).

4. **Появился дефект, который ломает чтение уже сейчас.** `get_topic_details` по самым наполненным темам отдаёт ответ, который MCP-клиент не принимает (BUG-109).
5. **Срок повторной проверки прошёл.** «Не позже начала ноября» истёк до деплоя R16; ориентир «4 недели после деплоя» — около 2026-12-18.
