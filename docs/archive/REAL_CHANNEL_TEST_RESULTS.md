## ⚠️ Выявленные проблемы

### 1. Временные ошибки API
- **Проблема**: 502 Bad Gateway от OpenAI API
- **Частота**: Редко (~1 случай на 846 сообщений)
- **Причина**: Временные проблемы на стороне OpenAI
- **Решение**: Retry logic обрабатывает, но иногда исчерпываются попытки

### 2. Некорректные ответы LLM
- **Проблема**: `ValueError: LLM response missing required field: text_clean`
- **Частота**: Очень редко (2 случая на 846 сообщений = 0.2%)
- **Причина**: LLM иногда возвращает неполный JSON
- **Решение**: Требуется улучшение валидации и обработки edge cases

### 3. Прерывание обработки
- **Проблема**: 171 сообщение не обработано (20.3%)
- **Причина**: Прерывание пользователем во время длительной обработки
- **Решение**: Можно дообработать командой `process --channel`

## 🚀 Команды для воспроизведения

### Полный pipeline (рекомендуется)
```bash
python -m tg_parser.cli run --source labdiagnostica --out ./output
```

### Поэтапное выполнение
```bash
# 1. Инициализация
python -m tg_parser.cli init

# 2. Добавление источника
python -m tg_parser.cli add-source \
  --source-id labdiagnostica \
  --channel-id @labdiagnostica_logical

# 3. Сбор данных
python -m tg_parser.cli ingest \
  --source labdiagnostica \
  --mode snapshot

# 4. Обработка через LLM
python -m tg_parser.cli process \
  --channel labdiagnostica_logical

# 5. Тематизация
python -m tg_parser.cli topicize \
  --channel labdiagnostica_logical

# 6. Экспорт
python -m tg_parser.cli export \
  --channel labdiagnostica_logical \
  --out ./output_full
```

### Дообработка оставшихся сообщений
```bash
python -m tg_parser.cli process --channel labdiagnostica_logical
```
